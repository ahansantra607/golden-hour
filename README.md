# Golden Hour — Candle Storefront

A static, responsive storefront for Golden Hour. It is designed for GitHub Pages and has no customer accounts or admin dashboard.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then Save.
4. Wait for the Pages deployment to finish. The site address is https://ahansantra607.github.io/golden-hour/.

## Edit the catalogue
Edit products.json directly on GitHub. Each product has an id, name, category, price (INR), notes, description and visual colour values. Keep ids unique. Prices and product details here are sample content and must be checked before accepting orders.

## Orders
The cart builds a WhatsApp message for +91 80882 37874. Customers must press Send in WhatsApp. This static website does not automatically send email, take payments, reserve inventory or confirm an order. Confirm availability, shipping, payment and delivery with each customer yourself. Do not add private API keys to this public repository.

## Before launch
- Replace sample product descriptions and prices with verified information.
- Replace CSS-generated product illustrations with genuine product photography when available.
- Add your confirmed delivery, returns, candle-care and safety information.
- Check the WhatsApp number and test an order on mobile and desktop.
- Verify the business name and logo are available for your intended use.
- Add the site in Google Search Console and submit sitemap.xml. Search rankings are not guaranteed.
